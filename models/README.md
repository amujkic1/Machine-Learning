## Models

This folder contains Jupyter notebooks implementing and evaluating multiple **supervised machine learning models** for credit score classification.

Each notebook focuses on a specific algorithm and includes data preprocessing steps, model training, performance evaluation, and result analysis.

### Implemented Models

- **Decision Tree**  
  Implementation of decision tree classifiers with hyperparameter tuning and evaluation on both balanced and imbalanced datasets.

- **K-Nearest Neighbors (KNN)**  
  Distance-based classification using feature scaling, neighbor selection, and performance comparison across different values of *k*.

- **Neural Network**  
  Multi-layer perceptron model for multi-class classification, including architecture design, hyperparameter tuning, and class imbalance handling.

- **Ensemble Models**  
  Ensemble-based approaches such as Random Forest, AdaBoost, and Bagging to improve classification performance and robustness.

### Evaluation

Models are evaluated using:
- Accuracy, Precision, Recall, and F1-score
- Confusion Matrix
- ROC Curves and AUC
- Cross-validation techniques

The notebooks highlight the impact of model selection, hyperparameter tuning, and data balancing on classification performance.
